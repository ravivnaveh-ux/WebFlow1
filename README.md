# אתר סטודיו קו

אתר תדמית בעברית לעסק שבונה אתרים, עם ממשק ניהול פרטי ותהליך לקביעת שיחת עיון.

## הפעלה

נדרש Node.js 20 ומעלה. מתוך התיקייה מריצים `npm start` ופותחים `http://localhost:3000`.

הנתונים נשמרים בקובץ `data/site-data.json` שהשרת יוצר בהרצה הראשונה. בהעלאה לאחסון, יש לבחור סביבת Node.js עם אחסון קבוע ולשמור על התיקייה `data` בין עדכוני האתר.

## אירוח בדומיין משלך

האתר דורש שירות Node.js (גרסה 20 ומעלה), כתובת `PORT` שהספק מעביר, ואחסון קבוע לתיקיית הנתונים. אפשר להגדיר את נתיב האחסון באמצעות `DATA_DIR`. יש להגדיר `ADMIN_CODE` ייחודי לפני ההפעלה הראשונה בסביבת ייצור; השרת לא יאתחל חשבון ניהול עם הקוד המקומי הידוע. האחסון הנוכחי הוא קובץ JSON, ולכן יש להריץ מופע שרת יחיד ולחבר גיבויים. אין להעלות את `.env` או את `data/` למאגר ציבורי.

## כניסה לממשק הניהול

פותחים את האתר, גוללים לתחתית ובוחרים „ניהול האתר”, או פותחים `http://localhost:3000/admin`. קוד הכניסה הראשוני הוא `KAV-start-7319!`. מומלץ להחליף אותו בעמוד „אבטחה” לפני חשיפת האתר לציבור. אפשר להגדיר `ADMIN_CODE` לפני ההפעלה הראשונה.

הניהול מחולק לעמודים: סקירה, פגישות, זמינות, חבילות, תוכן ועיצוב, ואבטחה. בקשות חדשות ממתינות לאישור. אפשר לאשר או לדחות אותן; דחייה משחררת את המשבצת. אפשר לעדכן גם את שם הסטודיו, פרטי קשר, כותרות ותיאורים, צבע הדגשה, ימי ושעות פעילות, אורך שיחה, טווח הזמנה, תאריכים חסומים וחבילות. חבילות ברירת המחדל הן ₪2,000, ₪2,250 ו־₪2,500.

## מה מחובר כרגע

- מערכת הזמנות פנימית עם שמירה בצד השרת ובדיקת שעה פנויה לפני שמירת הזמנה.
- אימות מנהלת עם קוד מגובב, עוגיית Session מוגנת, והשהיה אחרי ניסיונות כניסה שגויים.
- לאחר בקשת שיחת עיון היא ממתינה לאישור ידני. באישור, התור מסומן כמאושר ונפתחת הודעת WhatsApp מוכנה עם שם הלקוחה, היום והשעה. המנהלת שולחת אותה ידנית מתוך WhatsApp.
- דוגמאות האתרים לפי תחום משתמשות בתמונות מקומיות בתיקיית `assets`, כדי שהאתר לא יהיה תלוי בשירות תמונות חיצוני.

## פרטים ושמירת מידע

טופס הפנייה מבקש שם, טלפון, כתובת אימייל ותיאור עסק אופציונלי כדי לתאם שיחה. הנתונים נשמרים מקומית בקובץ השרת; לפני עלייה לאוויר יש לבחור אחסון, להגדיר גיבויים ומדיניות פרטיות המתאימים לעסק שלך.
